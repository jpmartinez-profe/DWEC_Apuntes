
# Desarrollo Web en Entorno Cliente

**Desarrollo Web en Entorno Cliente (DWEC)** es el módulo en el que aprenderemos a crear aplicaciones web que cobran vida en el navegador.

A lo largo del curso trabajaremos con **HTML, CSS y JavaScript**, aprendiendo a manipular el **DOM**, responder a las acciones del usuario, el concepto de **asincronía**, consumir datos mediante **APIs**, trabajar con almacenamiento en el navegador y desarrollar aplicaciones web cada vez más interactivas y dinámicas.

JavaScript será nuestra principal herramienta para transformar una página web estática en una aplicación capaz de **pensar, reaccionar y comunicarse**.

Pero aprender a programar no consiste solamente en aprender sintaxis. Consiste en aprender a **resolver problemas, dividirlos en partes pequeñas y encontrar soluciones que funcionen**. Y, sobre todo, en aprender a no rendirse cuando aparece ese temido mensaje rojo en la consola. 😄

> 💡 **"Cualquier tonto puede escribir código que un ordenador entienda. Los buenos programadores escriben código que los humanos puedan entender."**
>
> — *Martin Fowler*

Y en el mundo de la web, JavaScript nos recuerda algo especialmente importante:

> 🌐 **"La web no es una colección de páginas; es una plataforma para crear experiencias."**

Durante este módulo iremos construyendo poco a poco esas experiencias. **Cada línea de código será un pequeño paso para pasar de ser usuario de la web a ser creador de ella.**

¡Bienvenidos a DWEC!
